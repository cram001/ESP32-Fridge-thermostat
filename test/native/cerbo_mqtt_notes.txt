Cerbo MQTT draft validation targets

- OFF mode makes no broker connection attempts.
- Reconnect backoff remains bounded at 5-60 seconds.
- Reconnect causes an immediate publish.
- Normal interval arithmetic remains correct across uint32_t millis() rollover.
- NAN / invalid role temperatures are not published as numeric values.
- Broker outage never blocks thermostat control.
- Wi-Fi outage never causes a tight reconnect loop.
- Retained MQTT values repopulate Node-RED after redeploy/restart.

These targets are captured here temporarily while the publisher is being wired into the application. Convert applicable timing/state checks into native tests before this draft PR is made ready for review, then remove this note file during the stale-artifact sweep.
